스터디 신청 페이지 PRD는 [`../prd/study-signup.md`](../prd/study-signup.md)에 있어요. 그대로 써도 돼요.

## 내 아이디어로 PRD 써보기

자기 아이디어로 바꾸고 싶다면 이 프롬프트를 쓰세요. 딱 하나만 지켜주세요. **여러 사람이 함께 보는 데이터가 있는 서비스**여야 해요.

```txt
내가 만들고 싶은 서비스는 [아이디어를 한두 문장으로]야.

이 아이디어로 한 장짜리 PRD를 Markdown으로 작성해줘.
순서는 반드시 다음 여섯 칸을 지켜줘.
1. 문제 정의
2. 사용자
3. 핵심 기능 (가장 중요한 행동 하나에 ★ 표시)
4. 유저 스토리 ([사용자]로서 [무엇]을 하고 싶다 형식)
5. Out of Scope
6. 기술 스택

기술 스택 칸은 Next.js, Supabase, GitHub, Vercel로 고정해줘.

첫 버전이니까 기능을 욕심내지 마.
로그인, 결제, 자동 알림은 Out of Scope로 보내고,
항목이나 모임을 여러 개 동시에 관리하지 말고
딱 하나만 다루도록 범위를 줄여줘.

비고에 화면에 넣을 예시 데이터를 적어줘.
실제 이름이나 연락처는 쓰지 마.
```

> 내 아이디어로 만들면 체크포인트(`study-signup`)와 내용이 달라요. 막혔을 때는 체크포인트를 참고용으로만 보세요.
