# 02 · Next.js로 화면 만들기

> 원문: https://app.notion.com/p/3b0ecd5a3ac28176b02ff9739f801e32 · 기준일 2026-10-21
> 원문이 바뀌었으면 원문을 따르세요. 끝난 상태: `checkpoints/01-screen`

에이전트는 **이 키트 폴더가 아니라 프로젝트를 만들 상위 폴더**에서 열어요. (예: `~/Projects`)

## 1. 준비 확인 (아무것도 만들지 않아요)

```txt
지금 이 컴퓨터에서 Next.js 프로젝트를 새로 만들 수 있는 상태인지 점검해줘.

확인할 것은 네 가지야.
1) Node.js가 설치돼 있는지, 버전이 20.9 이상인지
2) 지금 터미널의 위치가 프로젝트를 새로 만들기에 적절한 폴더인지
3) 이 폴더 안에 이미 study-signup 이라는 이름의 폴더가 있는지
4) 3000번 포트를 쓰고 있는 프로그램이 떠 있는지

아직 아무것도 설치하거나 만들지 말고, 확인한 결과만 표로 보여줘.
```

## 2. 프로젝트 만들기

```txt
아래 PRD를 참고해서 Next.js 프로젝트를 새로 만들어줘.

[여기에 스터디 신청 페이지 PRD를 붙여넣으세요]

조건은 다음과 같아.
- create-next-app으로 만들고, 프로젝트 이름은 study-signup 으로 해줘
- 지금 터미널이 있는 폴더 바로 아래에 만들어줘
- create-next-app이 추천하는 기본값을 그대로 써줘
  (TypeScript, ESLint, Tailwind CSS, App Router 포함)
- 이번 단계에서 만들 것은 모임 정보가 보이는 첫 화면까지만이야.
  신청 폼과 신청자 명단은 아직 만들지 마
- 화면에 넣을 모임 정보는 PRD 비고에 있는 예시 데이터를 그대로 써줘
  (주 1회 알고리즘 스터디, 매주 토요일 오전 10시, 정원 8명)
- 라이브러리를 임의로 추가하지 마
- 데이터베이스, 로그인, 결제, 알림 기능은 PRD의 Out of Scope니까 붙이지 마
- 이미 있는 폴더나 파일을 지우거나 덮어쓰지 마
- 작업이 끝나면 새로 만든 파일 목록과 개발 서버를 실행하는 명령을 표로 보여줘
```

## 3. 학습자용 규칙 넣기 (키트 사용자만)

새로 만든 `study-signup`에도 체크포인트와 같은 에이전트 규칙을 넣으면 이후 강의가 편해요.

```txt
vibecoding-starter 키트의 harness 폴더에 있는 AGENTS.md, CLAUDE.md, .claude 폴더를
study-signup 프로젝트에 복사하고, 키트의 docs/prd/study-signup.md를 PRD.md로 복사해줘.

- study-signup에 이미 있는 AGENTS.md와 CLAUDE.md는 덮어써도 돼.
  덮어쓰기 전에 지금 내용에 Next.js 안내 블록 말고 다른 내용이 있는지 확인하고 알려줘
- 키트의 checkpoints/01-screen/STEP.md도 STEP.md로 복사해줘
- 다른 파일은 건드리지 마
- 끝나면 복사한 파일 목록을 보여줘
```

## 4. 신청 폼과 명단 붙이기

```txt
study-signup 프로젝트의 app/page.tsx를 고쳐서
신청 폼, 신청자 수, 신청자 명단을 추가해줘.

아래는 PRD의 핵심 기능과 유저 스토리야.

[여기에 PRD의 "3. 핵심 기능"과 "4. 유저 스토리"를 그대로 붙여넣으세요]

작업 순서와 조건은 다음과 같아.

1. 먼저 신청자 데이터가 어떤 항목으로 이루어지는지 타입부터 정해서 보여줘.
   코드를 실제로 고치기 전에 타입만 먼저 제안하고 내 확인을 기다려
2. 내가 타입을 확인해준 뒤에만 화면 코드를 고쳐
3. 예시 데이터는 다음 세 명을 그대로 써줘
   김민준(카카오톡 ID), 이서연(이메일), 박지훈(카카오톡 ID)
4. 신청 버튼을 누르면 화면 안의 목록에만 새 신청자가 추가되게 해줘.
   데이터베이스나 서버 저장 기능은 붙이지 마
5. 신청자 수는 따로 계산하지 말고 명단의 길이를 세서 보여줘
6. 디자인은 최대한 단순하게. 색이나 장식을 새로 늘리지 마
7. 새 라이브러리를 추가하지 마
8. 기존 파일을 지우지 말고, 이번에 고친 파일 목록을 마지막에 알려줘
```
