# 지금 상태 점검

**이 스킬은 읽기만 해요.** 설치, 로그인, 파일 수정, `git init`, `add`, `commit`, `push`는 하지 마세요.

## 확인할 것

1. 지금 열린 폴더의 실제 경로, 그리고 Git 저장소의 루트
   - 프로젝트 폴더가 아니라 **상위 폴더 전체가 저장소**라면 가장 먼저 크게 알려주세요. 개인 문서까지 올라갈 수 있어요.
2. Node.js 버전 (Next.js는 20.9 이상이 필요해요), Git과 GitHub CLI(`gh`) 설치 여부
3. 현재 브랜치, 커밋이 있는지, 바뀐 파일
   - 아직 add하지 않은 변경, 이미 add한 변경, 처음 보는(추적하지 않는) 파일을 나눠서
4. 연결된 원격 저장소(remote) 주소. 주소 안에 인증 정보가 있으면 가려요
5. 마지막 커밋이 GitHub에도 올라가 있는지 (원격이 있을 때만)
6. `.gitignore`가 `node_modules`, `.next`, `.env*`를 막고 있는지, 이미 추적 중인 것은 없는지
7. `.env.local` 파일이 **있는지만** 확인하고 내용은 열지 마세요. `.env.example`에 적힌 변수 이름과 비교해 빠진 이름만 알려주세요
8. `STEP.md` 기준으로 지금 어느 강의 단계인지

## 보고 형식

초보자가 읽을 수 있게 표 하나로 정리하세요.

| 확인 항목 | 지금 상태 | 다음에 할 일 |
|---|---|---|

- 확인하지 못한 항목은 이유를 적어요.
- 비밀번호·토큰·열쇠의 실제 값은 출력하지 마세요.
- 마지막에 "지금 가장 먼저 할 일" 한 줄을 붙여요.
