# 스터디 신청 페이지

모임 정보를 한 화면에서 보고, 이름과 연락 수단만 남기면 신청이 끝나는 페이지예요.
Next.js로 만들었어요.

이 프로젝트는 화면 담당과 처리 담당이 한 프로젝트 안에서 어떻게 나뉘는지 배우기 위한 실습이에요.

## 실행하기

Node.js 20.9 이상이 필요해요.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열어요.

## 지금 알아둘 것

신청 정보는 **브라우저 안에서만 유지돼요.** 새로고침하면 방금 남긴 신청이 사라지고, 다른 사람이 남긴 신청도 보이지 않아요.
신청을 실제로 적어두는 창고(데이터베이스)는 아직 붙이지 않았어요.
