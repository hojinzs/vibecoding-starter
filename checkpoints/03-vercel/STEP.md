# 지금 단계: Vercel 배포 끝

이 폴더는 강의 「Vercel로 배포하기」를 마친 상태예요.
(노션: https://app.notion.com/p/3b7ecd5a3ac2812b8ef8c14207993fc9)

## 지금까지 한 일

- 화면을 만들고(「Next.js로 화면 만들기」), 코드를 내 GitHub private 저장소에 올렸어요(「GitHub에 소스 올리기」).
- GitHub 저장소를 Vercel에 연결해 `https://study-signup-xxxx.vercel.app` 같은 주소를 받았어요.
- `git push` 한 번으로 다시 배포되는 걸 확인하려고 페이지 위쪽 문구를 "함께 공부할 사람을 찾고 있어요"로 바꿨어요.

| 자리 | 지금 어디에 |
|---|---|
| 화면 담당 | 사용자의 브라우저 |
| 처리 담당 | Vercel의 서버 |
| 기록 담당 | **아직 없어요** |
| 코드와 변경 기록 | GitHub |
| 사용자의 입구 | 배포된 서비스 주소 |

## 체크포인트에서 이어가는 경우

이 폴더에는 Git 기록과 Vercel 연결이 들어 있지 않아요. 내 GitHub private 저장소에 올린 뒤 vercel.com에서 **Add New → Project → Import**로 연결해요. 빌드 설정은 손대지 않아요.
Vercel 가입·연결은 계약서에 서명하는 일이라 **학습자가 직접 화면에서** 해요.

## 일부러 안 되는 것 (정상이에요)

- **휴대폰에서 남긴 신청이 컴퓨터 화면에 안 보여요.** 배포는 화면을 나눠주는 일이지 기억을 나눠주는 일이 아니에요. 지금 배포한 건 인터넷에 붙여둔 전단지에 가까워요.
- 새로고침하면 신청이 사라져요.

## 알아둘 것

- `main`에 push하면 곧바로 실제 서비스가 바뀌어요. 확인하지 않은 변경은 올리지 마세요.
- 시험해보고 싶은 변경은 다른 브랜치로 올리면 Preview 주소가 따로 생겨요.
- 문제가 생기면 먼저 Vercel의 Deployments 탭에서 이전 배포로 되돌리고, 그다음에 천천히 고쳐요.
