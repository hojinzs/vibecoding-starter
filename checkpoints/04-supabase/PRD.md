# 스터디 신청 페이지 PRD

> 원문: 노션 공통 강의안 「내 코드와 서비스는 어디에서 실행될까?」 8장
> https://app.notion.com/p/3a7ecd5a3ac2813f9b65f07083fab5e9 · 기준일 2026-10-21

## 1. 문제 정의
스터디나 소모임을 열 때 신청을 오픈 채팅, 댓글, 쪽지로 받으면
명단이 한곳에 모이지 않는다.
누가 신청했는지 세어보려면 대화를 거슬러 올라가야 하고,
결국 손으로 다시 옮겨 적게 된다.
→ 모임 정보와 신청자 명단이 한 화면에 모여야 한다.

## 2. 사용자
- 주최자: 소규모 스터디를 열고 신청 링크를 공유하는 사람.
  모인 명단을 확인한다.
- 참가자: 링크를 받고 들어와 이름과 연락 수단을 남기는 사람.
  가입 없이 한 번에 끝내고 싶어 한다.

## 3. 핵심 기능
1. 모임 정보 보기
2. 신청 폼 작성하기   ★ 가장 중요한 행동
3. 현재 신청자 수 보기
4. 신청자 명단 보기

## 4. 유저 스토리
- 참가자로서, 모임 소개를 한 화면에서 보고 싶다.
  참여할지 빠르게 판단하기 위해서다.
- 참가자로서, 이름과 연락 수단만 남기고 신청을 끝내고 싶다.
  가입 절차 없이 참여 의사를 전하기 위해서다.
- 주최자로서, 신청자 명단을 바로 확인하고 싶다.
  인원을 파악해서 모임을 준비하기 위해서다.

## 5. Out of Scope
- 로그인과 계정
- 결제
- 자동 알림 메일
- 신청 취소와 수정
- 여러 모임 동시 운영

## 6. 기술 스택
Next.js (화면 담당과 처리 담당) · Supabase (기록 담당) ·
GitHub (코드 보관) · Vercel (배포와 실행)

  모임: 주 1회 알고리즘 스터디, 매주 토요일 오전 10시, 정원 8명
  신청자: 김민준(카카오톡 ID), 이서연(이메일), 박지훈(카카오톡 ID)
- 실제 이름과 연락처는 넣지 않는다.
