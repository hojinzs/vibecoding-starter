# vibecoding-starter

코딩 경험 없이 **AI 에이전트와 함께 웹서비스를 만들고 배포하는 법**을 배우는 사람을 위한 동반 키트예요.
바이브코딩 공통 강의 ③장 「개발하고 배포하기」를 따라가며 쓰도록 만들었어요.

③장에서는 **스터디 신청 페이지**(`study-signup`)를 처음부터 만들어 인터넷에 올려요.

```
다시 정한다 → 만든다 → 올린다 → 붙인다 → 서비스가 된다
   (PRD)     (Next.js)  (GitHub)  (Vercel)   (Supabase)
```

## 이 키트에 들어 있는 것

| 폴더 | 무엇인가 |
|---|---|
| `checkpoints/` | 강의마다 끝난 상태의 `study-signup` 프로젝트 4개. 뒤처지거나 막혔을 때 여기서 이어가요 |
| `harness/` | 학습자를 지켜주는 에이전트 설정 원본. 모든 체크포인트에 이미 들어 있어요 |
| `docs/` | 강의 지도, PRD, 강의별 복사용 프롬프트 |

## 준비물

- Node.js 20.9 이상
- 코딩 에이전트 하나 (Claude Code, Antigravity, Codex 등)
- GitHub, Vercel, Supabase 계정 (해당 강의에서 직접 만들어요)

## 받는 법

Git을 아직 몰라도 돼요. GitHub 페이지의 **Code → Download ZIP**으로 받아 압축을 풀면 끝이에요.

## 두 가지 길

### 1. 처음부터 따라가기 (권장)

강의 순서대로 에이전트에게 PRD를 건네서 직접 만들어요. 강의별 프롬프트는 [`docs/prompts/`](docs/prompts/)에 있어요.

이 키트 폴더 **바깥**에 새 폴더를 만들어 작업하세요. 키트 안에서 만들면 GitHub에 올릴 때 키트 전체가 함께 올라갈 수 있어요.

### 2. 체크포인트에서 이어가기

강의를 놓쳤거나 내 프로젝트가 꼬였을 때 써요.

1. 이 키트 폴더를 에이전트로 열어요.
2. "Vercel 강의부터 이어갈래"처럼 말해요. 에이전트가 해당 체크포인트를 키트 옆 `study-signup` 폴더로 꺼내줘요.
3. 꺼낸 `study-signup` 폴더를 에이전트로 **다시 열고** 이어가요.

| 체크포인트 | 이런 상태예요 | 다음에 들을 강의 |
|---|---|---|
| `01-screen` | 화면 완성. 새로고침하면 신청이 사라져요 | GitHub에 소스 올리기 |
| `02-github` | README·`.gitignore` 정리 완료. GitHub에 올릴 준비가 됐어요 | Vercel로 배포하기 |
| `03-vercel` | 배포용 상태. 다른 기기에서 신청해도 안 보여요 | Supabase에 데이터 저장하기 |
| `04-supabase` | 신청이 Supabase에 쌓여요. ③장 도착점 | ④장 안전하고 제대로 만들기 |

각 체크포인트의 `STEP.md`에 그때까지 한 일과 **일부러 안 되는 것**이 적혀 있어요.

## 에이전트가 지켜주는 것

체크포인트에는 `AGENTS.md`와 `.claude/`가 들어 있어서, 에이전트가 이렇게 일해요.

- 바꾸기 전에 계획을 보여주고 확인을 기다려요.
- 무엇을 왜 했는지 카페 비유로 쉽게 알려줘요.
- 삭제, 기록 되돌리기, GitHub 업로드는 먼저 물어보고, force push는 하지 않아요.
- 비밀 열쇠를 출력하거나 대화창에 붙여달라고 하지 않아요.

자주 쓰는 말: "지금 상태 알려줘", "이거 뭐야?", "저장해줘", "배포해도 돼?"
